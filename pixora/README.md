# Pixora

Pixora — фотосоциальная сеть на Python / Flask. Пользователи могут создавать аккаунты, публиковать фотографии, ставить лайки, редактировать свои публикации и профили, искать пользователей и просматривать общую ленту.

## Возможности
- Регистрация, вход и выход; пароли хранятся в виде хешей.
- Общая лента с пагинацией и страница «Обзор».
- Загрузка JPG, PNG, GIF и WEBP (до 12 МБ).
- Лайки с уникальным ограничением в SQL.
- Профили, описание и сетка публикаций.
- Редактирование и удаление собственных публикаций.
- Поиск пользователей.
- PostgreSQL в production; SQLite локально.

## Запуск
Python 3.11+. Выполните `pip install -r requirements.txt`, затем `python app.py`. Откройте http://127.0.0.1:5000.

Перед публичным запуском задайте уникальный SECRET_KEY, настройте PostgreSQL и постоянное хранилище изображений, добавьте CSRF-защиту, rate limiting и модерацию.
