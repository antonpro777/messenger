# Picfy

Отдельный фронтенд-прототип фотосоциальной сети Picfy. Создан в папке `picfy/` и не меняет приложение Messenger.

## Запуск
Открой `index.html` в браузере или запусти локальный статический сервер из этой папки, например:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`.

## Что работает
- Адаптивная лента и блок историй.
- Демонстрационные карточки публикаций и рекомендации.
- Лайки, сохранение, комментарии и копирование ссылки.
- Диалог создания публикации с предпросмотром локального изображения.
- Мобильная нижняя навигация.

## Важно
Это клиентский демонстрационный интерфейс. Аккаунты, настоящие подписки, загрузка фото на сервер, хранение публикаций и личные сообщения пока не подключены. Данные новых публикаций живут только в текущей вкладке браузера.
