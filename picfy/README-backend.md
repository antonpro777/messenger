# Picfy

Picfy — фотосоциальная сеть на Flask. Общая база Supabase хранит аккаунты, публикации, лайки и подписки, а Supabase Storage — изображения.

## Возможности
- Регистрация, вход и выход; пароли хранятся в виде хешей.
- Общая лента и Explore для всех пользователей.
- Загрузка JPG, PNG, GIF и WEBP (до 12 МБ) в Supabase Storage.
- Общие лайки с уникальным ограничением в SQL.
- Профили с количеством публикаций, подписчиков и подписок.
- Подписка и отписка от пользователей.
- Редактирование и удаление собственных публикаций.
- Поиск пользователей.

## Локальный запуск
Python 3.13+. Установите зависимости командой `pip install -r requirements.txt`, задайте переменные окружения из `.env.example`, затем выполните `python app.py`. Без `DATABASE_URL` локально используется SQLite; без Supabase-переменных изображения сохраняются локально.

## Развёртывание на Vercel
1. Импортируйте GitHub-репозиторий `antonpro777/messenger` в Vercel.
2. В настройках проекта установите **Root Directory** = `picfy`.
3. Добавьте Environment Variables:
   - `SECRET_KEY` — длинная случайная строка для подписи сессий.
   - `DATABASE_URL` — PostgreSQL connection string из Supabase (лучше Session/Transaction Pooler, с SSL).
   - `SUPABASE_URL` — URL проекта Supabase.
   - `SUPABASE_SERVICE_ROLE_KEY` — серверный ключ Supabase Storage. Никогда не добавляйте его в Git, браузерный код или публичные переменные.
4. Перезапустите deployment после добавления переменных.

Supabase project: `gamigpluabnzzynecbrl`; bucket: `picfy-uploads`. Bucket публичный для чтения фотографий, а загрузка и удаление выполняются сервером с секретным ключом.

Перед публичным запуском включите проверку почты, CSRF-защиту, ограничение частоты запросов и модерацию пользовательского контента.
